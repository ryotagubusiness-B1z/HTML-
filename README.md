# ゲームブック フォーマット

CSV と画像（将来的に動画）を動的に読み込み、選択肢クリックでページ遷移する
ローカル動作のゲームブックです。**`data/data.csv` と `img/` の中身を差し替えるだけ**で
別作品に流用できます。タイトル画面も CSV（`page=0`）で制御するため、
**`index.html` を手で編集する必要はありません。**

## ファイル構成

```
index.html            … エントリーポイント（編集不要。中身は data.csv から制御）
/css/main.css         … レイアウト・レスポンシブ制御（Mac/Win/モバイル）
/css/page.css         … 配色・装飾（作品ごとに調整可）
/js/script.js         … 本体（CSV読込・ページ遷移）
/data/data.csv        … 物語データ（ここを編集）
/data/data.js         … data.csv を埋め込んだファイル（ダブルクリック配布用・自動生成）
/img/                 … 画像・動画ファイル（ここに配置）
/tools/csv-to-js.html … ビルドツール（配布ZIP生成／data.js生成）
```

## CSV の項目（1行目はヘッダー固定）

| 列名 | 内容 | 型 / 備考 |
|------|------|-----------|
| `page` | ページ番号 | 整数。必須・重複不可。**`0` はタイトル画面**として扱われます |
| `text` | 本文 | 文字列。**空欄可**（画像内に文章を持たせる場合）。`page=0` のときは**作品名**としてブラウザのタブ名に使われます |
| `image` | 画像／動画ファイル名 | 文字列。`img/` からの相対名。空欄可 |
| `choice1_text` | 選択肢1のテキスト | 文字列。`page=0` では「はじめる」ボタンの文言 |
| `choice1_to` | 選択肢1の遷移先ページ番号 | 整数。`page=0` では通常 `1` |
| `choice2_text` / `choice2_to` | 選択肢2 | `page=0` では `choice2_text` を**クレジット**として下中央に表示（`choice2_to` は不要） |
| `choice3_text` / `choice3_to` | 選択肢3 | 同上 |

- 選択肢は**最大3つ**。テキストと遷移先の両方が入った選択肢だけ表示されます。
- 選択肢が0個のページは終端となり、「おわり」と**「TOPへ」ボタン**（タイトル= `page=0` へ戻る）が表示されます。
- 文字コードは **UTF-8**（BOM付き可）で保存してください。
- 本文にカンマ・改行を含めるときは、そのセルを `" "` で囲みます
  （Excel等で改行を含むセルを保存した場合と同じ形式）。

### タイトル画面の例（`page=0` の行）

```csv
0,作品タイトル,title.png,はじめる,1,(c) 2026 作者名,,,
```

→ タイトル画像（上詰め中央）＋「はじめる」ボタン（中央）＋クレジット（下中央）。

## レイアウトについて（画像中心）

- 1ページにつき画像（または動画）を1枚、**幅いっぱい（最大720px）・上詰め中央**で表示します。
- 画像は**縮小されません**。縦長画像などで選択肢が画面に入りきらない場合は、
  **下にスクロール**すると画像の下に選択肢が表示されます。
- 画像／動画は拡張子で自動判定します。
  動画対応拡張子：`mp4 / mpg / mpeg / mov / m4v / webm / ogv`
  （※ 実際の再生可否は各ブラウザのコーデック対応に依存します）

## 操作

- タイトル（`page=0`）の「はじめる」で開始。
- 選択肢クリックでページ遷移。
- **ブラウザの戻る**で前のページへ戻れます。
- 終端ページの「TOPへ」でタイトルに戻れます。
- タブを閉じる／開き直すとタイトルに戻ります（セーブなし）。
- 対応ブラウザ：Chrome / Edge / Safari / Firefox（PC・スマホ）

## 制作・確認のしかた

`index.html` を**ダブルクリックで直接開くと CSV を読み込めません**
（`file://` では `fetch` が制限されるため）。制作・確認時はローカルサーバー経由で開きます：

```bash
# このフォルダ内で実行（どちらか）
python3 -m http.server
npx serve
```

その後ブラウザで `http://localhost:8000` を開きます。

> データの読み込みは ①`data.csv`(fetch) → ②`data.js`(埋め込み) → ③ファイル選択 の順に自動対応します。
> **`file://`（ダブルクリック）では①が使えないため、必ず②の `data.js` が使われます。**
> 編集中の `data.csv` をダブルクリックで確認したい場合は、先に下記で `data.js` を作り直してください。

## 配布フォルダ（ZIP）の作り方

`tools/csv-to-js.html` を**ローカルサーバー経由で開き**、「配布ZIPを生成」を押すと、
配布用の `dist.zip` がダウンロードされます。

- 含まれるもの：`index.html` / `css/` / `js/` / `data/data.js` / `img/`（CSVが参照する画像のみ）
- **含まれないもの**：`README.md` / `tools/` / `data/data.csv`
- 各ファイルは**コメントを除去**し、データは `data.js` に埋め込まれます
  （素人による改ざん・流用を多少しにくくするため）。
- 生成された `dist.zip` を解凍すれば、`index.html` のダブルクリックで動作します。

> `data.csv` だけを編集してダブルクリック確認したい場合は、同ツールの
> 「data.js だけを生成」から `data.js` を作って `data/` に上書きしてください
> （こちらはファイルを直接開いても使えます）。
