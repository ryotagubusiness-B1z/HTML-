# ゲームブック フォーマット

CSV と画像（将来的に動画）を動的に読み込み、選択肢クリックでページ遷移する
ローカル動作のゲームブックです。**`data/data.csv` と `img/` の中身を差し替えるだけ**で
別作品に流用できます。

## ファイル構成

```
index.html            … エントリーポイント（タイトル画面）
/css/main.css         … レイアウト・レスポンシブ制御（Mac/Win/モバイル）
/css/page.css         … 配色・装飾（作品ごとに調整可）
/js/script.js         … 本体（CSV読込・ページ遷移）
/data/data.csv        … 物語データ（ここを編集）
/data/data.js         … data.csv を埋め込んだファイル（ダブルクリック配布用・自動生成）
/img/                 … 画像・動画ファイル（ここに配置）
/tools/csv-to-js.html … data.csv → data.js 変換ツール（ブラウザで開くだけ）
```

## 動かし方（3つの方式に自動対応）

読み込みは次の順で自動的に切り替わります。**用途に応じて使い分けてください。**

| # | 方式 | こんなときに | 準備 |
|---|------|--------------|------|
| ① | ローカルサーバー / Web公開 | 自分で制作・確認するとき、同人サイトで公開するとき | サーバーで配信（下記） |
| ② | データ埋め込み（`data.js`） | ZIPで配布し、購入者にダブルクリックで開いてほしいとき | `data.js` を同梱 |
| ③ | CSVファイル選択 | ①②が使えないとき（保険） | 不要（画面の指示に従う） |

### ① ローカルサーバー / Web公開（制作・確認向け）

`index.html` を**ダブルクリックで直接開くと CSV を読み込めません**
（`file://` では `fetch` が制限されるため）。確認時はローカルサーバー経由で開きます：

```bash
# このフォルダ内で実行（どちらか）
python3 -m http.server
npx serve
```

その後ブラウザで `http://localhost:8000` を開きます。
同人サイト等でWeb公開する場合は、そのままアップロードすれば動作します。

### ② ダブルクリックで開けるように配布する（`data.js`）

`file://` でも動かすには、CSVの内容を `data/data.js` に埋め込みます。
`tools/csv-to-js.html` をブラウザで開き、`data.csv` を選ぶだけで `data.js` を生成・
ダウンロードできます（コマンド不要）。生成した `data.js` を `data/` に上書きして配布すれば、
購入者は `index.html` をダブルクリックするだけで遊べます。

> **メモ**: `data.csv` を編集したら `data.js` も作り直してください。
> サーバー/Web公開時は `data.csv` が優先されるため `data.js` は無視されます（古くても影響なし）。

### ③ CSVファイル選択（保険）

①②のどちらも使えない場合、起動時にCSV選択画面が表示されます。
`data.csv` を選ぶ／ドラッグ＆ドロップすると読み込まれます。

対応ブラウザ：Chrome / Edge / Safari / Firefox（PC・スマホ）

## CSV の項目（1行目はヘッダー固定）

| 列名 | 内容 | 型 / 備考 |
|------|------|-----------|
| `page` | ページ番号 | 整数。必須・重複不可。最初のデータ行が開始ページ |
| `text` | 本文 | 文字列。**空欄可**（画像内に文章を持たせる場合） |
| `image` | 画像／動画ファイル名 | 文字列。`img/` からの相対名。空欄可 |
| `choice1_text` | 選択肢1のテキスト | 文字列 |
| `choice1_to` | 選択肢1の遷移先ページ番号 | 整数 |
| `choice2_text` / `choice2_to` | 選択肢2 | 同上 |
| `choice3_text` / `choice3_to` | 選択肢3 | 同上 |

- 選択肢は**最大3つ**。テキストと遷移先の両方が入った選択肢だけ表示されます。
- 選択肢が0個のページは「おわり」（物語の終端）になります。
- 文字コードは **UTF-8**（BOM付き可）で保存してください。
- 本文にカンマ・改行を含めるときは、そのセルを `" "` で囲みます
  （Excel等で改行を含むセルを保存した場合と同じ形式）。

## メディアについて

- 1ページにつき画像（または動画）を1枚表示します。
- 拡張子で画像／動画を自動判定します。
  動画対応拡張子：`mp4 / mpg / mpeg / mov / m4v / webm / ogv`
  （※ 実際の再生可否は各ブラウザのコーデック対応に依存します）
- 画像・動画は**画面内に必ず収まるよう**（はみ出さず）表示されます。
  横長（3:2・4:3・16:9）／縦長（2:3・3:4・9:16）いずれにも対応。

## 操作

- タイトル画面の「はじめる」で開始。
- 選択肢クリックでページ遷移。
- **ブラウザの戻る**で前のページへ戻れます。
- タブを閉じる／開き直すとタイトル画面に戻ります（セーブなし）。
