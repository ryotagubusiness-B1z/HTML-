配布用フォルダ(ZIP)を生成

data.csv と img/ から、配布用の ZIP を生成します。
生成物には次が含まれません：README.md / tools/ / data.csv。
各ファイルはコメントを除去し、データは data/data.js に埋め込みます（ダブルクリックで動作）。

※ このツールはローカルサーバー経由で開いてください（プロジェクト直下で python -m http.server 等を実行し、http://localhost:8000/tools/csv-to-js.html を開く）。 ファイルを直接(file://)開くと、隣のファイルを読み込めず生成できません。

data.js だけを生成（簡易）

編集した data.csv を選ぶと、data.js だけをダウンロードします。 data/ に上書きすればダブルクリックでの動作確認に使えます。 （こちらはファイルを直接開いても使えます）
